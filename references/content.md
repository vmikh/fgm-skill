# Content consistency

- **Identify the entity and context.** The same record in the same state has the same facts across views. A different date, filter, or state may change what is shown.
- **Keep one source.** Use the project's current dataset when available. Record stable IDs, provenance, and the date for new fixtures. Mark demo values as synthetic.
- **Check relationships.** Confirm that names match their images, summaries match their details, and totals match their parts. Keep unknown and inapplicable values distinct.
- **Design with realistic variation.** Include long labels, missing assets, and relevant empty or final states. Preserve existing examples during content updates.
- **Sync before delivery.** Check each affected view against the source. Record any surface that still needs synchronization.
